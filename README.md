# Wilderness Safeguard
A collection of tools to make the Wilderness safer.

## High Risk Worlds
On High Risk worlds, removes menu options that teleport you into the Wilderness. Each teleport group can be toggled in the config:

- Ancient teleports (Carrallanger, Dareeyak, Annakarl, Ghorrock): spells, tablets, POH portals
- Ice Plateau (Lunar)
- Cemetery (Arceuus)
- Burning amulet
- Wilderness sword
- Revenant cave teleport scroll
- Wilderness crabs teleport
- POH wilderness obelisk

POH portals, the portal nexus and the jewellery box are covered by the matching teleport groups above.

## Item Warnings
While you carry a checked item (inventory or equipped), every Wilderness teleport above is removed on all worlds, and an infobox shows the item you need to bank:

- Imbued heart
- Saturated heart
- Chugging barrel
